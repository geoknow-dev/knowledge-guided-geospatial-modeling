# Data availability

Raw rasters are intentionally not included in this repository. They are large, may have redistribution restrictions, and the current local collection does not contain complete provenance and licence metadata for every region.

Expected logical inputs are listed in `configs/data_paths.example.json`:

- DEM and filled DEM
- flow accumulation
- annual and monthly precipitation for 2022
- land cover
- silt, sand, clay and soil organic carbon
- NDVI

Before a public release, record for each dataset: exact product and version, provider, persistent URL or DOI, access date, licence, spatial/temporal coverage, preprocessing steps, CRS, cell size, NoData value and checksum. If redistribution is prohibited, publish only the download and preprocessing instructions.
