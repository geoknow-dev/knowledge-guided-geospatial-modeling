# Result tables

- `task_metrics.csv`: WQI, spatial R², nRMSE and KCPI for M1–M3 across the six knowledge conditions.
- `code_generation_metrics.csv`: values reported in the paper's code-quality table.
- `knowledge_level_gain.csv`: DAG-step-weighted KCPI and adjacent-level KLG, recalculated with weights M1:M2:M3 = 1:4:8.
